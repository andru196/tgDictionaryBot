# tgDictionaryBot

Личный голосовой дневник в Telegram, который разбирается локальной LLM и превращается в один красивый HTML-файл.

Наговариваешь боту что попало — что съел, что заболело, какая мысль пришла, что надо загуглить. Потом запускаешь анализ: локальный Whisper расшифровывает голосовые, локальная модель в LM Studio раскладывает речь по категориям, детерминированный код считает корреляции «еда → симптом», и на выходе получается отчёт.

**Ничего не уходит наружу.** LLM локальная, распознавание локальное, база локальная. Единственное соединение с интернетом — long polling к Telegram.

## Как это устроено в двух абзацах

Telegram Bot API хранит непрочитанные апдейты только 24 часа, поэтому «включу сервис в конце года и заберу всё» не работает. Система разделена на два процесса: лёгкий **Collector** крутится всегда и просто складывает сырьё в SQLite, а тяжёлый **CLI** запускается руками когда захочется отчёт.

Разбор идёт по состояниям (`Captured → Transcribed → Extracted`), каждый шаг идемпотентен: упало на 300-м голосовом — перезапуск продолжит с 301-го. Рядом с каждым результатом пишется версия модели и промпта, так что после апгрейда Qwen можно переразобрать историю задним числом, не трогая исходники.

Ключевое разделение ответственности: **LLM только извлекает структуру из речи, а считает всё обычный код.** Восьмимиллиардная модель не воспроизводима и плохо считает — доверять ей статистику нельзя. Корреляции, окна экспозиции и точный тест Фишера живут в доменном слое и покрыты unit-тестами.
